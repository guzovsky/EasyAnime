# 🎌 EasyAnime

> **Status:** 🧪 Setup and R&D. Everything is subject to change.

An AniList-inspired app with extra functionality and planned AI-powered features.

---

## 🚀 Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Tooling:** Ultracite (with Biome and Husky) + GraphQL Codegen
- **API:** AniList GraphQL API

---

## 🛠️ Development Setup

```bash
# Install dependencies
pnpm install

# Generate GraphQL types
pnpm codegen

# Run local development server
pnpm dev
```
